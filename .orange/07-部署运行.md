# 07 部署运行

## 7.1 安装

```bash
# 新版（推荐）
pip install langchain              # langchain_v1（主库）
pip install langchain-core         # 核心抽象
pip install langchain-anthropic    # Anthropic/Claude 集成
pip install langchain-openai       # OpenAI 集成
pip install langgraph              # 执行引擎（必需）

# 旧版（仅迁移用）
pip install langchain              # 包含 langchain-classic（已废弃）
```

**推荐的 pyproject.toml:**
```toml
[dependencies]
langchain = ">=1.0.0"         # langchain_v1
langchain-core = ">=0.3.0"
langchain-anthropic = ">=0.3.0"
langgraph = ">=0.4.0"
```

## 7.3 基础运行示例

```python
from langchain_anthropic import ChatAnthropic
from langchain.agents import create_agent
from langchain_core.messages import HumanMessage
from langchain_core.tools import tool

@tool
def search(query: str) -> str:
    """Search the web for information."""
    return f"Results for: {query}"

# 创建 Agent
model = ChatAnthropic(model="claude-sonnet-4-5")
agent = create_agent(model=model, tools=[search])

# 同步调用
import asyncio
result = asyncio.run(
    agent.ainvoke({"messages": [HumanMessage("What is Python?")]})
)
print(result["messages"][-1].content)
```

## 7.4 Checkpointer 持久化（生产环境）

### InMemorySaver（开发）

```python
from langgraph.checkpoint.memory import InMemorySaver

agent = create_agent(
    model=model,
    tools=tools,
    checkpointer=InMemorySaver(),
)
```

### PostgresSaver（生产）

```bash
pip install langgraph-checkpoint-postgres psycopg[binary]
```

```python
from langgraph.checkpoint.postgres import PostgresSaver

with PostgresSaver.from_conn_string(
    "postgresql://user:pass@localhost:5432/db"
) as checkpointer:
    checkpointer.setup()  # 创建表

    agent = create_agent(
        model=model,
        tools=tools,
        checkpointer=checkpointer,
    )

    # 多轮对话
    config = {"configurable": {"thread_id": "user-123"}}
    await agent.ainvoke({"messages": [HumanMessage("Hello")]}, config=config)
    await agent.ainvoke({"messages": [HumanMessage("Continue")]}, config=config)
```

## 7.5 LangGraph Platform 部署

langchain_v1 的 create_agent 返回 CompiledStateGraph，可直接部署到 LangGraph Platform：

```python
# langgraph.json（项目配置）
{
  "dependencies": ["."],
  "graphs": {
    "agent": "./my_agent.py:agent"
  }
}
```

```bash
# 本地开发服务器
pip install "langgraph-cli[inmem]"
langgraph dev

# 部署到云端
langgraph deploy
```

部署后提供 REST API:
```bash
# 创建线程
curl -X POST http://localhost:8123/threads

# 发送消息
curl -X POST http://localhost:8123/threads/{thread_id}/runs \
  -d '{"input": {"messages": [{"role": "human", "content": "Hello"}]}}'
```

## 7.6 从 Classic 迁移

### 旧版代码（废弃）

```python
# ❌ 旧版 - langchain-classic
from langchain.agents import AgentExecutor, create_react_agent
from langchain import hub

prompt = hub.pull("hwchase17/react")
agent = create_react_agent(llm, tools, prompt)
executor = AgentExecutor(agent=agent, tools=tools, verbose=True)
result = executor.invoke({"input": "..."})
```

### 新版代码（推荐）

```python
# ✅ 新版 - langchain_v1
from langchain.agents import create_agent
from langchain_core.messages import HumanMessage

agent = create_agent(model=llm, tools=tools)
result = await agent.ainvoke({"messages": [HumanMessage("...")]})
```

### Memory 迁移

```python
# ❌ 旧版 Memory（已废弃）
from langchain.memory import ConversationBufferMemory
memory = ConversationBufferMemory()
chain = LLMChain(llm=llm, memory=memory, prompt=prompt)

# ✅ 新版 Checkpointer
from langgraph.checkpoint.memory import InMemorySaver
agent = create_agent(model=llm, tools=tools, checkpointer=InMemorySaver())
# 通过 thread_id 维护对话历史
```

### 主要差异

| 特性 | AgentExecutor | create_agent |
|------|--------------|-------------|
| 调用方式 | `.invoke()` 同步 | `.ainvoke()` 异步（推荐） |
| 输入格式 | `{"input": "..."}` | `{"messages": [HumanMessage("...")]}` |
| 输出格式 | `{"output": "..."}` | `{"messages": [...]}` |
| 持久化 | 无 | Checkpointer |
| 中断恢复 | 无 | interrupt_before/after |
| 并行工具 | 无 | ToolNode 并行 |

## 7.7 LCEL 部署（简单管道）

无需 Agent 时，LCEL 管道直接部署：

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_anthropic import ChatAnthropic
from langchain_core.output_parsers import StrOutputParser

chain = (
    ChatPromptTemplate.from_template("Summarize: {text}")
    | ChatAnthropic(model="claude-haiku-4-5")
    | StrOutputParser()
)

# 流式输出
async def stream_response(text: str):
    async for chunk in chain.astream({"text": text}):
        yield chunk

# FastAPI 集成
from fastapi import FastAPI
from fastapi.responses import StreamingResponse

app = FastAPI()

@app.post("/summarize")
async def summarize(text: str):
    return StreamingResponse(stream_response(text))
```
