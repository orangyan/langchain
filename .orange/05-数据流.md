# 05 数据流

## 5.1 旧版 AgentExecutor 数据流（已废弃）

```
用户输入: "What is the capital of France?"
    │
    ▼
AgentExecutor._call()
    │
    ▼ 迭代循环 (max_iterations=15):
┌───────────────────────────────────────────────────────┐
│                                                       │
│ 1. Agent.plan(intermediate_steps, input=...)          │
│    ↓ 调用 LLMChain.predict()                          │
│    ↓ LLM 生成文本:                                    │
│    "Thought: I need to search for this               │
│     Action: Search                                    │
│     Action Input: capital of France"                  │
│    ↓ OutputParser.parse() → AgentAction               │
│                                                       │
│ 2. AgentExecutor._perform_agent_action(action)        │
│    ↓ 找到 name="Search" 的工具                        │
│    ↓ tool.run("capital of France")                    │
│    ↓ 返回 "Paris"                                     │
│                                                       │
│ 3. intermediate_steps.append((action, "Paris"))       │
│    scratchpad = "Action: Search\nObservation: Paris"  │
│                                                       │
│ 4. 下一轮 LLM 调用（含 scratchpad）:                  │
│    "Thought: I now know the answer                    │
│     Final Answer: The capital of France is Paris."    │
│    → AgentFinish → 返回                               │
└───────────────────────────────────────────────────────┘
```

## 5.2 新版 create_agent 数据流（基于 LangGraph）

```
用户输入: {"messages": [HumanMessage("...")]}
    │
    ▼
create_agent() 构建的 LangGraph 图
    │
    ▼ LangGraph Pregel 超步:

超步 1: {START → agent_node}
    ├── AgentMiddleware.before_agent(state)
    ├── AgentMiddleware.before_model(request)
    ├── AgentMiddleware.wrap_model_call(call) → 包装后的 LLM 调用
    ├── llm.bind_tools(tools).invoke(messages)  ← 实际 LLM 调用
    ├── AgentMiddleware.after_model(state)
    └── 写入 messages channel: AIMessage(tool_calls=[...])

超步 2: {agent_node → tools_node} (如果有工具调用)
    ├── AgentMiddleware.wrap_tool_call(call) → 包装后的工具调用
    ├── AgentMiddleware.before_tool(request)
    ├── ToolNode 并行执行所有 tool_calls
    │   ├── tool_1.ainvoke(args_1)
    │   ├── tool_2.ainvoke(args_2)
    │   └── tool_3.ainvoke(args_3)
    ├── AgentMiddleware.after_tool(state)
    └── 写入 messages channel: [ToolMessage(...) × N]

超步 3: {tools_node → agent_node} (继续推理)
    ├── ... (同超步 1)
    └── 直到 LLM 返回无工具调用 → route → END

超步 N: {agent_node → END}
    └── AgentMiddleware.after_agent(state)
    └── 返回最终状态
```

## 5.3 Middleware 数据流（中间件链）

```
用户调用 agent.ainvoke(input)
    │
    ▼
middleware[0].before_agent(state)
    → middleware[1].before_agent(state)
        → middleware[2].before_agent(state)
            → 实际 agent 执行
        ← middleware[2].after_agent(state)
    ← middleware[1].after_agent(state)
← middleware[0].after_agent(state)
    │
    ▼
(LLM 调用时)
middleware[0].before_model(request)
    → middleware[1].before_model(request)
        → ...
            → 实际 LLM 调用
        ← ...
    ← middleware[1].after_model(state)
← middleware[0].after_model(state)
```

## 5.4 LCEL 管道数据流

```python
chain = prompt | llm | output_parser

# 等价于:
# RunnableSequence([prompt, llm, output_parser])

chain.invoke({"input": "Hello"})
    │
    ▼
prompt.invoke({"input": "Hello"})  → ChatPromptValue
    │
    ▼
llm.invoke(ChatPromptValue)  → AIMessage
    │
    ▼
output_parser.invoke(AIMessage)  → str
    │
    ▼
返回最终字符串
```

**流式 LCEL:**
```
chain.astream({"input": "Hello"})
    │
    ▼ (每个 token)
output_parser 接收 AIMessageChunk
    └── yield str_chunk
```

## 5.5 Callback 数据流

LangChain 通过 Callback 系统实现日志、追踪、成本统计：

```
LLM 调用前 → on_llm_start(serialized, prompts, **kwargs)
    │
    ▼ LLM 生成
LLM token 流 → on_llm_new_token(token, *, chunk, ...)
    │
    ▼ LLM 完成
LLM 调用后 → on_llm_end(response, **kwargs)
    │
    ▼ 或异常
LLM 错误 → on_llm_error(error, ...)
```

**LangSmith 集成（自动追踪）:**
```bash
export LANGCHAIN_TRACING_V2=true
export LANGCHAIN_API_KEY=your_key
# 之后所有 .invoke() 调用自动记录到 LangSmith
```
