# 03 技术架构

## 三层包架构

```
langchain-core (基础抽象层)
    ├── BaseLanguageModel       LLM 抽象
    ├── BaseTool / StructuredTool  工具抽象
    ├── BaseMessage             消息类型（Human/AI/System/Tool）
    ├── Runnable                可链接接口（.invoke/.astream/.batch）
    ├── BasePromptTemplate      提示词模板
    └── BaseOutputParser        输出解析器

langchain-classic (旧版，已废弃)
    ├── AgentExecutor           简单 while 循环 Agent
    ├── Agent / BaseSingleActionAgent  旧版 Agent 接口
    ├── ConversationBufferMemory  基于内存的对话历史
    ├── LLMChain                LLM + Prompt 组合
    └── ... (所有 Classic 内容从 0.3.1 起废弃)

langchain_v1 (新版主库)
    ├── create_agent()          基于 LangGraph 的 Agent 工厂
    ├── AgentMiddleware         中间件协议（8 个钩子）
    ├── ResponseFormat          输出格式策略
    └── ... (新 API，活跃维护)
```

## langchain-core 关键抽象

### BaseLanguageModel

```python
# libs/core/langchain_core/language_models/base.py

class BaseLanguageModel:
    def invoke(self, input: LanguageModelInput) -> BaseMessage
    async def ainvoke(self, input: LanguageModelInput) -> BaseMessage
    def stream(self, input: LanguageModelInput) -> Iterator[BaseMessageChunk]
    def bind_tools(self, tools: list[BaseTool]) -> "BaseLanguageModel"
    def with_structured_output(self, schema: type) -> Runnable
```

### BaseTool

```python
# libs/core/langchain_core/tools/base.py

class BaseTool(BaseModel):
    name: str
    description: str
    args_schema: Optional[Type[BaseModel]] = None
    return_direct: bool = False
    response_format: str = "content"  # "content" | "content_and_artifact"
    extras: dict = {}  # vendor-specific 扩展

    def invoke(self, input: Union[str, dict]) -> Any
    async def ainvoke(self, input: Union[str, dict]) -> Any
    def _run(self, *args, **kwargs) -> Any       # 子类实现
    async def _arun(self, *args, **kwargs) -> Any  # 子类实现（可选）
```

### Runnable 协议

```python
# LCEL 的核心接口
class Runnable(Protocol):
    def invoke(self, input: Input, config: Config = None) -> Output
    async def ainvoke(self, input: Input, config: Config = None) -> Output
    def stream(self, input: Input, ...) -> Iterator[Output]
    async def astream(self, input: Input, ...) -> AsyncIterator[Output]
    def batch(self, inputs: list[Input], ...) -> list[Output]
    def __or__(self, other: Runnable) -> RunnableSequence  # 管道运算符
    def bind(self, **kwargs) -> "Runnable"                  # 绑定参数
    def with_retry(self, ...) -> "Runnable"                 # 添加重试
```

## AgentMiddleware 架构（langchain_v1）

```python
# libs/langchain_v1/langchain/agents/middleware/types.py

@dataclass
class ModelRequest:
    messages: list[BaseMessage]
    tools: list[BaseTool]
    model_kwargs: dict

@dataclass
class ToolCallRequest:
    tool_name: str
    tool_args: dict
    tool_call_id: str

@dataclass
class AgentState:
    messages: list[BaseMessage]
    # ... 其他状态

class AgentMiddleware(Protocol):
    # 8 个钩子，全部可选实现
    async def before_agent(self, state: AgentState) -> AgentState: ...
    async def after_agent(self, state: AgentState) -> AgentState: ...
    async def before_model(self, request: ModelRequest) -> ModelRequest: ...
    def wrap_model_call(self, call: ModelCallFn) -> ModelCallFn: ...
    async def after_model(self, state: AgentState) -> AgentState: ...
    def wrap_tool_call(self, call: ToolCallFn) -> ToolCallFn: ...
    async def before_tool(self, request: ToolCallRequest) -> ToolCallRequest: ...
    async def after_tool(self, state: AgentState) -> AgentState: ...
```

**中间件执行顺序:**
```
before_agent → before_model → wrap_model_call → [LLM 调用]
    → after_model → wrap_tool_call → before_tool → [工具调用]
        → after_tool → before_model (循环) → ... → after_agent
```

## 技术栈

| 组件 | 技术 |
|------|------|
| **语言** | Python 3.9+ |
| **序列化** | Pydantic v2 |
| **异步** | asyncio |
| **LLM 集成** | langchain-anthropic, langchain-openai, langchain-google-genai... |
| **向量存储** | Chroma, FAISS, Pinecone（via langchain-community） |
| **工具** | DuckDuckGo, Wikipedia, Python REPL（via langchain-community） |
| **测试** | pytest + pytest-asyncio |
