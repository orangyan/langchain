# 01 产品介绍

## 项目背景

LangChain 于 2022 年末由 Harrison Chase 创建，是最早、最流行的 LLM 应用开发框架。在 AI 应用爆发期，它定义了 "Chain"、"Agent"、"Memory" 等 AI 应用的基本概念，GitHub 星标曾超过 90,000。

## 架构演进

LangChain 经历了重大的架构重写：

```
LangChain Classic (2022-2024)          LangChain v1 (2024+)
    Chain / LLMChain                       create_agent (基于 LangGraph)
    AgentExecutor（简单 while 循环）        AgentMiddleware（8 钩子中间件）
    Memory（ConversationBufferMemory）      LangGraph Checkpointer
    Tool（BaseTool）                        BaseTool（保持兼容）
    LCEL（LangChain Expression Language）   LCEL（继续支持）
```

## 当前状态（2024+）

| 包 | 状态 | 说明 |
|----|------|------|
| `langchain-core` | ✅ 活跃维护 | 基础抽象（BaseLanguageModel, BaseTool, Runnable） |
| `langchain` (classic) | ❌ 已废弃 | AgentExecutor, ConversationBufferMemory 等 |
| `langchain_v1` | ✅ 新版主库 | create_agent, AgentMiddleware |
| `langchain-community` | ⚠️ 维护中 | 第三方集成（工具、LLM 适配器） |
| `langchain-anthropic` | ✅ 活跃 | Anthropic Claude 集成 |
| `langchain-openai` | ✅ 活跃 | OpenAI 集成 |

## 与 LangGraph 的关系

```
langchain-core
    ↑ 提供基础抽象
langchain_v1
    ↑ 在 LangGraph 之上构建高级 Agent API
langgraph
    ↑ 执行引擎（StateGraph, Pregel, Checkpointer）
```

`langchain_v1` 的 `create_agent` 内部构建一个 `LangGraph StateGraph`。LangChain 变成了 LangGraph 的"高级封装层"，而不再是独立执行引擎。

## 目标用户

- **快速原型开发者**: 用 `create_agent` 几行代码搭建 Agent
- **企业应用开发者**: 通过中间件系统管理生产级 Agent 行为
- **多 Provider 用户**: langchain-core 统一了不同 LLM 的调用接口
- **迁移用户**: 从 LangChain Classic 迁移到 LangGraph 生态
