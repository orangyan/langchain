# 08 记忆架构

## 8.1 架构演进：Memory → Checkpointer

LangChain 的记忆系统经历了彻底重写：

```
Classic 记忆（已废弃）          新版记忆（基于 LangGraph）
─────────────────────          ─────────────────────────
ConversationBufferMemory        Checkpointer（短期，per-thread）
ConversationSummaryMemory       BaseStore（长期，cross-thread）
ConversationTokenBufferMemory   SummarizationMiddleware（自动压缩）
VectorStoreRetrieverMemory      向量存储直接集成（无 Memory 包装）
```

**废弃原因：**
- `ConversationBufferMemory` 存在状态竞争问题（非线程安全）
- 无法持久化到数据库
- 不支持多用户（无 thread 隔离）
- 与 LangGraph 的 Channel 机制不兼容

---

## 8.2 新版记忆：Checkpointer（短期）

Checkpointer 通过 LangGraph 的 `thread_id` 机制实现会话内记忆：

```python
from langgraph.checkpoint.memory import InMemorySaver
from langchain.agents import create_agent

agent = create_agent(
    model=model,
    tools=tools,
    checkpointer=InMemorySaver(),  # 内存（开发用）
)

# 每次调用带 thread_id → 自动恢复历史消息
config = {"configurable": {"thread_id": "user-alice"}}
await agent.ainvoke({"messages": [HumanMessage("My name is Alice")]}, config=config)
await agent.ainvoke({"messages": [HumanMessage("What is my name?")]}, config=config)
# → "Your name is Alice."（记住了上文）
```

**Checkpointer 种类：**

| 类型 | 用途 | 包 |
|------|------|-----|
| `InMemorySaver` | 开发/测试 | `langgraph` |
| `PostgresSaver` | 生产环境 | `langgraph-checkpoint-postgres` |
| `ShallowPostgresSaver` | 只保留最新检查点 | `langgraph-checkpoint-postgres` |
| `AsyncPostgresSaver` | 异步生产环境 | `langgraph-checkpoint-postgres` |

## 8.3 新版记忆：BaseStore（长期，跨 thread）

`BaseStore` 是 LangGraph 提供的跨会话存储，用于保存用户偏好、知识等：

```python
from langgraph.store.memory import InMemoryStore
from langchain.agents import create_agent

store = InMemoryStore()

agent = create_agent(
    model=model,
    tools=tools,
    store=store,  # 注入 Store
    checkpointer=InMemorySaver(),
)

# 在工具中访问 Store
from langchain_core.tools import tool
from langgraph.store.base import BaseStore

@tool
def remember_preference(key: str, value: str, store: BaseStore = None):
    """Save a user preference."""
    store.put(("preferences",), key, {"value": value})
    return f"Saved {key}={value}"

@tool
def recall_preference(key: str, store: BaseStore = None):
    """Recall a user preference."""
    item = store.get(("preferences",), key)
    return item.value["value"] if item else "Not found"
```

**BaseStore 接口：**

```python
class BaseStore:
    def put(self, namespace: tuple, key: str, value: dict) -> None
    def get(self, namespace: tuple, key: str) -> Optional[Item]
    def delete(self, namespace: tuple, key: str) -> None
    def list_namespaces(self, prefix: tuple) -> list[tuple]
    def search(self, namespace: tuple, query: str) -> list[Item]
```

## 8.4 自动上下文压缩（SummarizationMiddleware）

当 token 数超限时，`summarization` 中间件自动压缩历史：

```python
from langchain.agents.middleware import summarization

agent = create_agent(
    model=model,
    tools=tools,
    middleware=[
        summarization(
            model=ChatAnthropic(model="claude-haiku-4-5"),  # 压缩用的便宜模型
            max_tokens=4096,   # 超过时触发压缩
            keep_last_n=5,     # 保留最近 N 条消息不压缩
        )
    ],
    checkpointer=InMemorySaver(),
)
```

**压缩流程：**
```
before_model 钩子触发
    ↓ 检查 token 数 > 4096
    ↓ 取 messages[:-5]（历史部分）
    ↓ 调用 claude-haiku 生成摘要
    ↓ 替换为 SystemMessage(摘要) + messages[-5:]
    ↓ 继续正常 LLM 调用
```

## 8.5 旧版 Memory 对比（已废弃）

```python
# ❌ ConversationBufferMemory（废弃）
from langchain.memory import ConversationBufferMemory
memory = ConversationBufferMemory(return_messages=True)
chain = LLMChain(llm=llm, memory=memory, prompt=prompt)
# 问题：非线程安全，无法持久化，耦合到 Chain

# ✅ 替代方案：Checkpointer
agent = create_agent(model=llm, tools=[], checkpointer=InMemorySaver())

# ❌ ConversationSummaryMemory（废弃）
from langchain.memory import ConversationSummaryMemory
memory = ConversationSummaryMemory(llm=llm)

# ✅ 替代方案：SummarizationMiddleware
agent = create_agent(
    model=llm, tools=[],
    middleware=[summarization(model=llm, max_tokens=4096)]
)
```

## 8.6 与其他项目记忆架构对比

| 特性 | LangChain (新版) | LangGraph | deer-flow | hermes-agent | nanobot | gstack |
|------|----------------|-----------|-----------|-------------|---------|--------|
| **短期记忆** | LangGraph Checkpointer | Checkpointer | Checkpointer | 无 | memdir/ (手动) | git WIP commit |
| **长期记忆** | BaseStore (可选) | BaseStore | 无 | 无 | memdir/ JSON | learnings.jsonl |
| **压缩机制** | SummarizationMiddleware | 无内置 | 无 | 无 | compact/ 服务 | 无 |
| **跨 thread** | BaseStore | BaseStore | 无 | 无 | 无 | 无 |
| **向量搜索** | VectorStore 直接集成 | 无内置 | 无 | 无 | 无 | 无 |
| **存储后端** | PostgreSQL/内存 | PostgreSQL/内存 | PostgreSQL/内存 | 无 | 文件系统 | 文件系统 |
| **持久化** | ✅ Checkpointer | ✅ Checkpointer | ✅ Checkpointer | ❌ | ✅ 文件 | ⚠️ 有限 |

**关键洞察：**
- LangChain v1 是所有项目中记忆架构最完整的（短期+长期+压缩）
- LangChain 和 LangGraph 共享同一 Checkpointer 生态
- Classic Memory（ConversationBufferMemory）已完全废弃，不要使用
