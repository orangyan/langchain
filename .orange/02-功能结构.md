# 02 功能结构

## 2.1 旧版：AgentExecutor（已废弃）

```python
# langchain_classic/agents/agent.py - 不要在新代码中使用

from langchain.agents import AgentExecutor, create_react_agent
from langchain import hub

prompt = hub.pull("hwchase17/react")
agent = create_react_agent(llm, tools, prompt)
agent_executor = AgentExecutor(agent=agent, tools=tools, verbose=True)
result = agent_executor.invoke({"input": "..."})
```

**内部实现（ReAct 循环）:**
```python
class AgentExecutor(Chain):
    def _iter_next_step(self, ...):
        # 1. LLM 生成 Action + Action Input
        output = self.agent.plan(intermediate_steps, **kwargs)
        # 2. 解析输出
        if isinstance(output, AgentFinish): return output
        # 3. 执行工具
        tool_result = self._perform_agent_action(output)
        return tool_result

    def _call(self, inputs, ...):
        intermediate_steps = []
        for _ in range(self.max_iterations):  # 默认 15 次
            output = self._iter_next_step(intermediate_steps, ...)
            if isinstance(output, AgentFinish): return output
```

**废弃原因:**
- 无持久化（无 Checkpointer）
- 无并行工具执行
- 无中断/恢复支持
- 无流式输出（原生）
- 无子图支持

**内部构建的 LangGraph 图:**
```python
def create_agent(model, tools, middleware, ...):
    # 构建 LangGraph StateGraph
    builder = StateGraph(AgentState)
    builder.add_node("agent", _build_agent_node(model, middleware))
    builder.add_node("tools", ToolNode(tools))
    builder.add_conditional_edges("agent", _route_tools_or_end)
    builder.add_edge("tools", "agent")
    return builder.compile(checkpointer=InMemorySaver())
```

## 2.3 AgentMiddleware 系统

```python
# langchain_v1/agents/middleware/types.py

from langchain.agents.middleware import (
    # 内置中间件
    model_call_limit,      # 限制 LLM 调用次数
    model_retry,           # LLM 调用失败自动重试
    tool_retry,            # 工具调用失败自动重试

    pii,                   # PII 数据脱敏

```

**自定义中间件:**
```python
from langchain.agents.middleware.types import AgentMiddleware, ModelRequest, AgentState

class LoggingMiddleware(AgentMiddleware):
    async def before_model(self, request: ModelRequest) -> ModelRequest:
        print(f"Calling LLM with {len(request.messages)} messages")
        return request

    async def after_model(self, state: AgentState) -> AgentState:
        last_msg = state.messages[-1]
        print(f"LLM responded: {last_msg.content[:100]}...")
        return state

agent = create_agent(
    model=llm,
    tools=tools,
    middleware=[LoggingMiddleware()],
)
```

## 2.4 ResponseFormat 策略

```python
# langchain_v1/agents/response_format.py

response_format="auto"       # AutoStrategy: 自动检测（默认）
response_format="tool"       # ToolStrategy: 使用工具调用返回结构化输出
response_format="provider"   # ProviderStrategy: 使用 Provider 的结构化输出 API
```

**AutoStrategy 检测逻辑:**
1. 如果模型支持 structured_output → 用 ProviderStrategy
2. 如果模型支持 tool_calls → 用 ToolStrategy
3. 否则 → 解析文本输出

## 2.5 LCEL（LangChain Expression Language）

LCEL 是 LangChain 的 Runnable 组合语法，在新版中仍然支持：

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_anthropic import ChatAnthropic
from langchain_core.output_parsers import StrOutputParser

# Runnable 链（用 | 运算符组合）
chain = (
    ChatPromptTemplate.from_template("Summarize: {text}")
    | ChatAnthropic(model="claude-haiku-4-5")
    | StrOutputParser()
)

result = chain.invoke({"text": "..."})
# 异步流式
async for chunk in chain.astream({"text": "..."}):
    print(chunk, end="")
```

LCEL 主要用于非 Agent 的简单 LLM 管道（不需要工具调用和多轮对话）。
